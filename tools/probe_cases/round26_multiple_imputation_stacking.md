# Missing-data analysis

Twenty multiply imputed datasets were generated by chained equations for 480
randomized participants. Each completed dataset contained all 480 participants.
To obtain one final analysis file, the 20 completed datasets were appended,
producing 9,600 rows. A standard logistic regression was then fitted to this
appended file as if all rows represented independent participants. The reported
standard errors and p values came directly from that single regression; no
within-imputation and between-imputation variance pooling was performed.

# Results

The treatment odds ratio was 0.81 (95% CI 0.77 to 0.85, p<0.001), and the
manuscript concludes that the treatment effect is highly precise and robust to
missing data.
