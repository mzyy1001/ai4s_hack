## A. 图谱解析

### A.1 图表分类

先分类，再按类型套用对应的抽取模板。

| 类型 | 识别线索 | 必抽字段 |
| --- | --- | --- |
| `dose_response` | x 轴为浓度/剂量，常为对数轴，S 形拟合曲线 | 剂量范围与梯度、拟合模型、IC50/EC50 及 CI、Hill 斜率、拟合优度、平台值 |
| `statistical_plot` | 柱状/箱线/点图 + 误差棒 + 显著性标记 | 分组、n、误差类型、显著性标记对应的 p 值与检验 |
| `survival` | 阶梯状递减曲线，x 轴为时间 | 分组、风险人数表、中位生存、HR 及 CI、log-rank p、删失标记 |
| `workflow` | 方框-箭头流程图，CONSORT / PRISMA | 各节点人数/样本数、排除原因与数量、流入流出是否守恒 |
| `micrograph` | 显微/组化/荧光图像 | 放大倍数、比例尺、染色方法、通道、视野数、配套定量图是否存在 |
| `blot` | WB / 凝胶条带 | 目标蛋白、分子量、内参、泳道标注、是否有拼接痕迹、定量方式 |
| `heatmap` | 网格色块 + 色标 | 聚类方法、标准化方式、色标范围、行列含义、样本数 |
| `flow_cytometry` | 二维散点 + 门控 | 门控策略、各象限百分比、对照（FMO/isotype）、事件数 |
| `schematic` | 手绘/示意模型图 | 不抽数值；核查是否被误当作数据呈现 |

### A.2 数值抽取的证据分级

严格按此优先级取值，并在 `key_data.source` 中如实标注：

```
figure_caption（图注明文）> text（正文明文）> table > figure_axis（读坐标轴刻度）> figure_pixel（像素估读）
```

**硬性规则**：
- `figure_pixel` 来源的数值一律 `confidence: low`，且必须写成区间（如 `"12–15 μM"`），**禁止给点值**。
- 坐标轴为对数轴时，线性估读必然错误 —— 先确认轴类型再读数。
- 误差棒长度不得直接当作 SD/SEM 报告，除非图注写明。
- 图中显著性星号必须回查图注中的星号定义（`*p<0.05` 的阈值各刊不同）。

### A.3 原图定位

每条 `figure_record` 必须给出：

```
"location": {
  "figure_label": "Figure 3",
  "panel": "B",
  "page": 7,
  "first_cited_at": "sec:results§3.2",
  "image_file": "figures/g003.png"
}
```

PDF 输入时 `page` 必填；缺页码的定位视为无效定位。

### A.4 输出

`figure_record`，模式见 `../schemas/figure_record.schema.json`。除上述字段外还包含：
`interpretation`（一段自然语言图表解读：这张图在回答什么问题、结论是什么）、
`extracted_data[]`（复用 `key_data` 结构）、`issues[]`（本图触发的 finding）。

## B. 图表使用规范校验

### B.1 类型是否匹配研究目的

**待填充**：敏仪基于自身统计图/实验流程图制作经验，梳理"研究场景 → 应选图表类型"对照表。骨架：

| 研究场景 | 推荐图表 | 常见误用 |
| --- | --- | --- |
| 少量分组的连续变量比较 | 箱线图 / 点图（显示个体数据点） | 用柱状图掩盖分布（bar chart of continuous data） |
| 剂量-效应关系 | 半对数曲线 + 拟合 | 用柱状图割裂剂量连续性 |
| 相关性 | 散点图 + 拟合线 + CI | 只给 r 值不给散点 |
| 时间序列/纵向 | 折线图 | 用堆叠柱状图 |
| 组成/占比 | 堆叠柱 / 表格 | 3D 饼图 |
| 高维分组比较 | 热图 + 聚类 | 过多并列子图 |

### B.2 设计规范核查

- 坐标轴：是否标注变量名与单位？y 轴是否截断（truncated axis 夸大差异）？对数轴是否标明？
- 误差棒：是否说明类型？n 是否标注？
- 显著性：星号定义是否在图注给出？是否标注了具体检验方法？
- 显微图：**是否有比例尺**（缺比例尺是硬伤）？放大倍数是否标注？是否给出配套定量？
- 配色：是否对色觉障碍友好？热图色标是否发散型用于非发散数据？
- 图注是否自足（脱离正文可读懂）？
- 是否存在图像不当处理（过度对比度调整、条带拼接无分隔线、重复面板）？

### B.3 创新画法

会议纪要要求：**如有较为创新的图表方法，是否有足够证据支撑**。判据草案：
- 非标准图表是否在图注或方法中说明构造方式与读法？
- 是否同时提供了标准图表或原始数据作为交叉验证？
- 若无说明且无原始数据 → `novel_chart_unexplained`，severity `major`。

### B.4 冗余度

- 同一数据是否既画图又列表（信息冗余）？
- 图表数量与内容量是否匹配？
- 是否有图表可合并或移入补充材料？
