## 1. 输入

## 2. 校验清单

### 2.1 检验方法是否匹配数据类型

**待填充**：核心交付物是一张"数据类型 × 设计 → 应选检验"对照表。骨架：

| 数据类型 | 设计 | 应选检验 | 常见误用 |
| --- | --- | --- | --- |
| 连续、正态、两组独立 | 平行 | 独立样本 t | 用配对 t |
| 连续、正态、两组配对 | 前后 | 配对 t | 用独立 t |
| 连续、非正态 | 两组 | Mann-Whitney U | 强行用 t 而未验正态性 |
| 连续、正态、≥3 组 | 平行 | one-way ANOVA + 事后检验 | 做多次两两 t 检验 |
| 连续、两因素 | 析因 | two-way ANOVA | 拆成多个 one-way |
| 计数/比例 | 两组 | χ² / Fisher | 期望频数 <5 仍用 χ² |
| 生存时间 | — | Kaplan-Meier + log-rank / Cox | 用 t 检验比较中位生存 |
| 重复测量 | 纵向 | RM-ANOVA / 混合效应模型 | 当作独立样本 |

配套检查：正态性与方差齐性是否检验并报告？

### 2.2 样本量

- 是否有效能分析（power analysis）或样本量依据？
- `min_group_n` 是否低于该研究类型的通行下限？**待填充**：分研究类型的 n 下限建议值。
- n 是生物学重复还是技术重复？（技术重复冒充生物学重复是高频问题）
- 临床试验：是否报告了实际入组 vs 计划入组、失访率、是否 ITT 分析？

> 会议纪要明确：样本量判定属"无明确统一标准的模糊场景"，**优先从统计学与通用惯例等可量化维度切入**，
> 不做主观判断。因此本模块对样本量的输出应为"低于领域惯例，建议人工确认"而非"样本量不足，结论无效"。

### 2.3 多重比较

- 同一数据集做了多少次检验？是否校正（Bonferroni / Holm / FDR-BH）？
- 组学数据是否报告了 adjusted p / q 值？
- 是否存在"选择性报告"迹象（只报显著结果、终点在事后更换）？

### 2.4 报告完整性

- p 值：是否给出精确值（而非只写 `p<0.05`）？是否报告了检验统计量与自由度？
- 误差：SD / SEM / 95%CI 是否明确标注？（图中用 SEM 却在文中称 SD 是常见错误）
- 效应量：是否报告？只有 p 值没有效应量时应提示。
- 缺失数据如何处理？

### 2.5 分领域规范

**待填充**：蒋运基于药企实习与公开数据库挖掘经验，按研究方向梳理对应官方指南
（如临床试验 ICH E9 / CONSORT，观察性研究 STROBE，动物实验 ARRIVE，诊断 STARD，组学 MIAME）。

## 3. category slug（待补全）

| slug | 说明 | severity |
| --- | --- | --- |
| `wrong_test` | 检验方法与数据类型不匹配 | critical |
| `sample_size` | 样本量低于领域惯例 / 无效能分析 | major |
| `no_multiple_comparison_correction` | 多重比较未校正 | major |
| `assumption_unchecked` | 未验证正态性/方差齐性 | major |
| `error_bar_ambiguous` | 误差类型未标注或前后不一致 | minor |
| `p_value_incomplete` | 仅报告 p<0.05，无精确值/统计量 | minor |
| `no_effect_size` | 未报告效应量 | minor |
| `selective_reporting` | 疑似选择性报告 / 终点更换 | critical |
