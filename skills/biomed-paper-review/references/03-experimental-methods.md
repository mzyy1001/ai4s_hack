# M3 · 实验方法合规性

**负责人：Peter** · 状态：**骨架 — 待负责人填充惯例库**

对应会议纪要"第二层：实验方法合规性校验"。对照**领域通用实验惯例库**，排查异常实验对象、
非通用流程等需要作者额外解释的场景。不判断方法在科学上是否最优，只判断是否偏离惯例而未加说明。

---

## 1. 输入

`structured_result_v2` 的 `design`（`arms[]` 含剂量/途径/周期、`controls`、`randomization`、
`blinding`）与 `measurement.assays[]`，加 `evaluation_matrix`（仅用于路由与定位证据）。
路由：仅当 `study_design.family ∈ {experimental, human_interventional}` 时启动完整检查。

## 2. 校验清单

### 2.1 方法是否有依据（reference）

- 每个 `assays[]` 项是否引用了方法学文献或试剂盒说明？
- 引用是否指向**原始方法学文献**，而非二手综述？
- 对已发表方法的改动是否明确说明并给出理由？

> **待填充**：常见 assay（WB / qPCR / ELISA / IHC / 流式 / MTT / 组织学）各自的"最低报告要素"清单
> —— 如 WB 必须报告抗体货号、稀释比、上样量、内参。

### 2.2 实验动物必要性

`has_animal_experiment = true` 时启动。判据草案：

| 问题 | 判定线索 |
| --- | --- |
| 该科学问题能否用体外/类器官/计算模型回答？ | 若结论未涉及整体生理、药代、行为、免疫互作，动物实验的必要性存疑 |
| 物种选择是否有依据？ | 是否说明为何用该物种/品系 |
| 是否遵循 3R（替代/减少/优化）？ | 与 M6 伦理模块联动 |
| 样本量是否为达成统计效能的最小量？ | 与 M4 联动，双向：过小无效，过大不伦理 |

> **待填充**：Peter 基于自身多类实验实操经验，梳理"动物实验必要 / 不必要"的典型场景对照表。

### 2.3 实验设计惯例

- 对照组类型是否恰当（vehicle / sham / placebo / untreated）？有无阴性对照缺失？
- 剂量梯度设置是否合理（组数、跨度、是否覆盖预期 EC50）？
- 时间点选择是否有依据？
- 生物学重复 vs 技术重复是否明确区分？
- 随机化与盲法：未做是否说明理由？
- 是否存在"异常实验对象"（罕见品系、非常规细胞系、来源不明的原代细胞）？

> **待填充**：生物医药领域通用实验设计惯例库 —— 会议纪要允许通过 agent 批量爬取顶刊已发表论文
> 的共性特征自行汇总，无需依赖官方标准文件。

### 2.4 细胞系与试剂溯源

- 细胞系是否做 STR 鉴定、支原体检测？
- 是否使用了 ICLAC 已知误认/交叉污染细胞系列表中的细胞系？
- 关键试剂（抗体、化合物）是否给出来源与批号？

## 5. 二期扩展：方法与试剂溯源核验（本期不实现，规则先写下）

一期只看"有没有引用方法学文献、有没有写试剂来源"，二期核验这些引用与来源**是否成立**。

### 5.1 方法学引用核验

- 数据源：Crossref / PubMed（标识符核验由 M1 执行）
- 检查：被引方法文献是否真实存在？是否已撤稿？被引文献中是否**真的包含**该方法？
  论文声称"按文献 X 方法执行"但 X 用的是另一套流程 —— 这是一期完全查不出的问题。

### 5.2 试剂与细胞系核验

- 数据源：Cellosaurus / ICLAC / RRID Antibody Registry
- 检查：细胞系是否在 ICLAC 误认列表中？抗体 RRID 是否存在、是否有已知特异性问题？
- 一期只能查"有没有写货号"，二期能查"这个货号对不对"。

### 5.3 实验惯例库外部化

一期的惯例库靠人工梳理 + agent 爬顶刊汇总；二期可将其升级为**动态库** ——
按研究方向实时检索同类论文的方法参数分布，判断本文的剂量/时长/n 是否落在常规区间外。
输出应为「偏离同类研究常规区间」这类事实描述 + 分布位置，不要直接判「方法错误」。
